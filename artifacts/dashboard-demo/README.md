# Dashboard product tour

English motion presentation using screenshots captured from the actual local application at http://127.0.0.1:3111. Includes the order board, operator workspace, supplied orders and an existing paused incident with recorded sources. No API model calls, incident mutations or bookings were made to create the tour. Data and services remain fictional/simulated. Approval is described as a product rule, not shown as a newly executed transaction.

`dashboard-demo.mp4` is the final film with the original CC0 ambient music normalised to -16 LUFS. Music source and dedication: ../openrouter-demo/MUSIC-LICENSE.txt.

`film.html` is the editable motion composition; PNG files are real application captures.
